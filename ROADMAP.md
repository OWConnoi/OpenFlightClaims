# Roadmap

## Completed

- Searchable airline directory
- Official-source passenger-rights guides
- Eligibility helper and claim template (browser-only)
- Public JSON, Markdown, OpenAPI, and MCP endpoints
- Multi-language support (EN, ES, FR, AR, UR)
- Multi-license setup (AGPL code, ODbL data, reserved trademarks)

## Up next

- More airline coverage through community contributions
- Additional locale-native guide translations
- Public changelog for dataset edits

This project stays minimal: no database, no auth, no admin panel, no CMS.
