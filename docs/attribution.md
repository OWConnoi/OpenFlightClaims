# Attribution

If you reuse OpenFlightClaims data, please include attribution.

## Example attribution text

For datasets:

> Airline claim-link data from OpenFlightClaims, licensed under ODbL 1.0.
> <https://github.com/OWConnoi/OpenFlightClaims>

For web pages or applications:

> Data source: OpenFlightClaims — open community directory of official airline
> claim links. Licensed under ODbL 1.0.

## Requirements

Under the ODbL, you must:

- Include or reference the ODbL license.
- Keep intact any notices on the Database.
- State clearly that the data is available under the ODbL.
- Not use the OpenFlightClaims name, logo, or visual identity as the primary
branding of a derivative work without written permission.

## What does not require attribution

- Using a small number of airline links for personal reference.
- Casual mention or linking to the project.
- Using the source code under AGPL terms (which has its own attribution rules).

## Airline trademarks

Airline names, logos, and trademarks belong to their respective owners.
OpenFlightClaims does not claim ownership of any airline marks.

For questions about attribution, open a GitHub discussion.

This is not legal advice.
