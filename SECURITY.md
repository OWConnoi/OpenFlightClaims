# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's security advisory feature. Do not open a public issue until the issue has been triaged.

## In scope

- Unsafe link handling
- Dependency vulnerabilities
- Build or CI configuration issues
- Malicious dataset entries
- XSS risks in rendered public data

## Out of scope

- Airline claim outcomes
- Legal advice
- Third-party airline website issues

## Privacy

OpenFlightClaims stores no user accounts or data. It is a static site. Reports go through GitHub issues, which are public.

## Disclaimer

OpenFlightClaims is not legal advice and does not process compensation claims.
